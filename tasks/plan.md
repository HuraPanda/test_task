# AI Gateway MVP — план

Основание: [актуальный MVP-контекст](../docs/sdd/SPEC_DRIVEN_DEVELOPMENT.md) и указание пользователя реализовать минимальную версию на React + Vite, Express, pg и PostgreSQL. Расширенная `docs/sdd/SPECIFICATION.md` — предыдущий проект; её пагинация, статусы заданий и дополнительные слои не входят в текущую реализацию.

## Реализация

- `server.mjs`: Express, создание таблиц при запуске, cookie-сессии, три маршрута, прямые SQL-запросы через `pg`, HTTP-запрос к OpenRouter. Без ORM и слоёв.
- `client/main.jsx`: один компонент с формой, ответами и кешем последних 50 записей в localStorage. React выводит текст без HTML-интерпретации.
- `client/style.css`, `client/index.html`, `vite.config.mjs`: оформление и сборка; Vite проксирует `/api`, Express отдаёт сборку.
- `compose.yaml`: PostgreSQL с постоянным volume; `.env.example`: настройки сервера.
- `test/gateway.test.mjs`: интеграционные проверки с настоящим PostgreSQL и локальным HTTP-сервером вместо платного AI API.

## Данные и API

`gateway_sessions`: UUID, хеш случайного cookie-токена, срок действия 30 дней.
`gateway_requests`: UUID, ссылка на сессию, запрос, ответ, время. Сохраняются успешные пары; ошибки выводятся в интерфейсе без отдельной модели заданий.

- `POST /api/session` → `{ sessionId }`, новая cookie только при отсутствии действующей сессии.
- `GET /api/history` → `{ items }`, последние 50 пар текущей сессии, новые сверху.
- `POST /api/requests { prompt }` → `201 { item }` после ответа ИИ и сохранения в БД.

Секретный cookie-токен не передаётся в JSON/localStorage. Публичный ID служит только ключом кеша. Кеш читается после подтверждения сессии и заменяется серверной историей. PostgreSQL хранит все успешные пары. Запросы независимы, без контекста прошлой переписки.

## Проверки

Нумерация соответствует пяти критериям актуального MVP-контекста:

- AC-1: cookie-сессия без входа; повторное открытие сохраняет сессию.
- AC-2: HTTP API провайдера получает введённый запрос.
- AC-3: ответ отображается в браузере.
- AC-4: история сохраняется после перезагрузки, кеш записывается в localStorage.
- AC-5: две сессии не получают историю друг друга.

Дополнительно: пустой запрос, сбой AI API, безопасный вывод текста, недоступный localStorage и сборка клиента.

## Ограничения

Без регистрации, стриминга, пагинации, rate limiting, автоматических повторов и выбора нескольких провайдеров. OpenRouter использует `POST /chat/completions`, [контракт API](https://openrouter.ai/docs/api_reference/overview). Для локальных тестов базовый URL подменяется переменной окружения.

Старый шахматный код и клиентские файлы удалены из репозитория: AI Gateway — единственное приложение проекта.
